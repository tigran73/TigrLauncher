# Как внести вклад

## Сперва — про рамки проекта

Проект сознательно держится на минимуме. Правила, которые важнее стиля кода:

1. **Никаких зависимостей.** Ни AndroidX, ни Kotlin, ни Gradle, ни Material. Только framework-API,
   потому что на 2 ГБ RAM и `armeabi-v7a` каждая библиотека — это десятки мегабайт и секунды старта.
2. **Скорость важнее красоты фич.** Если предложение добавляет слой (сервис, ContentObserver,
   ещё один `Activity`) — приложи замеры старта и памяти до/после.
3. **Один файл логики не страшен.** Весь лаунчер живёт в `MainActivity.java`, и это осознанно:
   так проще читать и дешевле по классам. Дробить на классы будем под конкретную боль, а не «для чистоты».
4. **Правки минимальные.** Не переформатировать соседние строки, не менять порядок объявлений,
   не тащить стилевые правки в чужой блок.
5. `minSdk` 26, `targetSdk` 28. Поднятие `targetSdk` меняет поведение фокуса и домашнего экрана,
   так что это отдельное обсуждение, а не часть фичи.

## Сборка и проверка

```bash
./build.sh                 # собирает TigrLauncher.apk
./deploy.sh                # собирает, ставит по adb, делает лаунчер домашним экраном
TV=192.168.1.20:5555 ./deploy.sh
```

Подробнее про `ANDROID_HOME`, `BUILD_TOOLS_VERSION`, `PLATFORM_VERSION`, `JAVA_HOME` — в README.

Замеры, которые уместно приводить в пул-реквесте:

```bash
adb shell am start -W -S -n com.tigran.tigrlauncher/.MainActivity   # время холодного старта
adb shell dumpsys meminfo com.tigran.tigrlauncher | grep TOTAL      # память
adb shell dumpsys input_method | grep mServedView                   # где сейчас фокус
```

Баги навигации проще всего воспроизводить клавиатурой/`input keyevent` и смотреть `mServedView`:
это быстро показывает, остался ли фокус на плитке или уехал на контейнер.

## Что бы пригодилось

- **Плитки источников (HDMI/тюнер).** `input id` берутся из `TvInputManager`
  (`dumpsys tv_input` показывает список). Нужно проверить, открывается ли вход на весь экран
  явным intent'ом без системных разрешений — на Realtek это под вопросом.
- **Клавиша «Сон».** `PowerManager.goToSleep()` требует системных разрешений, рабочий путь —
  `AccessibilityService` с `GLOBAL_ACTION_...`; важно не раздуть память.
- **Адаптивность размеров.** Сейчас всё размечено под канвас 960×540 dp (1920×1080 при плотности 320).
  Размерная сетка для других плотностей/разрешений — отдельная задача.
- **Кэш artwork на диск.** Сейчас плитка рисуется при первом показе, из-за этого холодный старт
  ~0.7–1.1 с вместо ~0.4 с. Помогает кэш собранных битмапов в `codeCacheDir`.
- **Тесты на другом железе.** Если запускал на другом железе — добавь строчку в README
  «Проверено на», это самая ценная информация.

## Формат пул-реквеста

- Что меняется и зачем (1–3 предложения).
- На каком устройстве и Android проверялось.
- До/после по старту и памяти, если правка влияет на них.
- Скриншот, если менялся интерфейс.
